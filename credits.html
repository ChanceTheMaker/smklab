SMK Lab is a directory and landing page by Chance Roth (@ChanceTheMaker). It brings together independent custom firmware and browser projects for M-VAVE SMK-37 Pro & Elite.

Firmware projects

  • Felucca SMK is based on Felucca by Leo Kuroshita (@kurogedelic), Hügelton Instruments.
  • Sloop SMK is based on Sloop by isod89, itself based on Felucca.
  • Melodee is a separate project by keremimo. Its SMK port is planned; this directory does not offer a Melodee SMK firmware download.

Artwork and site source

SMK illustrations and Studio screenshots are adapted from the Felucca SMK and Sloop SMK sites by Chance Roth. The illustrations are presentation artwork, not physical measurements. This site's source is distributed under GPL-3.0. Each linked project retains its own licenses and credits.

Privacy and submissions

This hub does not run analytics or request MIDI access. The submission form only opens GitHub with the information you enter. You must sign in and submit there; requests are public and subject to GitHub's policies. This hub does not automatically list submitted sites. Linked sites have their own privacy practices.
